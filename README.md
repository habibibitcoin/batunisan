# Jual Batu Nisan Sidoarjo

Website bisnis pembuatan batu nisan, prasasti, dan plakat kustom di Kepunten, Tulangan, Sidoarjo.

## Stack

- Vite 8
- Tailwind CSS 3 (PostCSS)
- Vanilla JavaScript (komponen modular)

## Perintah

```bash
npm install
npm run dev      # server pengembangan
npm run build    # hasil produksi di dist/
npm run preview  # pratinjau hasil build
```

## Deploy

Proyek ini terhubung dengan repository GitHub `habibibitcoin/batunisan` dan dideploy otomatis ke Vercel. Setiap push ke branch `main` memicu deployment produksi.
